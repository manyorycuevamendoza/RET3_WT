# Código Confianza — RET3 Women in Tech 2026

Prototipo interactivo de **Código Confianza** para BCP: una funcionalidad que permite a los usuarios verificar la identidad de un asesor durante una llamada telefónica mediante un código dinámico.

## Demo en vivo

🔗 **[ret3wt-codigo-confianza.vercel.app](https://ret3wt-codigo-confianza.vercel.app)**

## Estructura del proyecto

| Carpeta | Descripción |
|---------|-------------|
| `codigo-confianza-pwa/` | PWA interactiva — el prototipo desplegado en Vercel |
| `codigo-confianza/` | Composiciones de video (HyperFrames) para el pitch |
| `pitch-entrega/` | Materiales de entrega del pitch |

## Tecnologías

- HTML, CSS, JavaScript vanilla
- PWA (Service Worker + manifest)
- Desplegado en Vercel (static site)
