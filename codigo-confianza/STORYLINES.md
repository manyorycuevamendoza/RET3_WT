# Storylines — Código Confianza

## Picked: A — Un día en la bodega

**Device:** A moment in someone's day
**Form:** Object-to-object chain

The viewer follows Rosa's phone screen on her bodega counter. A push notification slides down, becomes the call screen, the call becomes the code input, and the code becomes the green verification. Each screen element causes the next. The phone never leaves the frame; the world around it shifts from the warm bodega to a clean BCP-blue verification space and back.

**First two seconds:** A stat — "55% ya no contesta" — large white type on a BCP blue ground. A phone vibrates on a counter.

**Beats:** hook → push permiso → llamada → código voz → push código → ingreso → verificado → error (brief) → regla de oro + end card

**Look:** White ground, BCP blue (#002A8D) ink, orange (#F37021) accent on the code digits only. Inter display.

**Sound:** Calm ambient bed, phone vibration, soft ticks on code entry, a pop on green verification, a buzz on error.

---

## B — Antes y después

Split screen: left side grey and tense (Rosa ignoring 3 calls, red X marks), right side calm BCP blue (the Código Confianza flow). The halves merge when the call is verified. Bold but harder to show the full 7-step flow.

## C — El código viaja

One continuous take: the 4-digit code as an orange object travels from BCP server → advisor screen → phone call → Rosa's notification → verified. Cinematic but abstract — risks losing the practical "how to use it" clarity a hackathon judge needs.
